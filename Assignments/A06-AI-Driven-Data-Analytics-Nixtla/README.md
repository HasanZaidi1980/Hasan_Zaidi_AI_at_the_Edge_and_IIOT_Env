## A06: AI Driven Data Analytics with Nixtla
- Problem: IIoT data is often sparse and noisy, making it difficult to build robust forecasting models for industrial temperature trends.
- Approach: I utilized AutoML (Nixtla) for model selection and implemented Generative AI (VAE) to create synthetic data to improve model robustness.
- Results: The MSTL and AutoARIMA models emerged as top performers, successfully capturing weekly and seasonal patterns in the sensor data.
