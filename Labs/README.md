## Course Laboratories
This directory contains my hands-on technical labs where I applied AI and IIoT concepts in simulated and real-world environments.

### Key Learning Outcomes:
Edge Deployment: I learned how to manage local data processing to reduce latency and enhance privacy.

- Hardware Interfacing: I practiced using the Edge Impulse CLI to profile models for Cortex-M4F microcontrollers.
- Protocol Analysis: I gained a deep understanding of the trade-offs between MQTT, CoAP, and OPC UA regarding security and efficiency.
- Advanced Analytics: I utilized AutoML and Generative AI (VAEs) to handle sparse and noisy industrial data.
