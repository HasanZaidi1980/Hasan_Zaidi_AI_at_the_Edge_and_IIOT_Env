## L02: Deploying an AI Model on a Simulated Edge Device
- What I did: I configured a simulated edge environment to test the deployment of a machine learning model. This involved setting up the necessary dependencies in a Jupyter Notebook and ensuring the model could run within the resource constraints of a virtual edge device.
- What I learned: I gained hands-on experience with the specific requirements of "Edge Intelligence," such as managing local data processing to minimize latency and privacy risks.
- Challenges faced: Ensuring that the TensorFlow environment was correctly configured to handle the model's specific versioning was a key hurdle I had to debug during the setup.
