    Overview

    This project simulates an Industrial Internet of Things (IIoT) sensor network using three primary industrial protocols: MQTT, CoAP, and OPC UA. The system generates synthetic environmental data (temperature and humidity) and provides a real-time graphical visualization of the data stream.

    Folder Structure

    • mqtt_sensor_simulation.py
    • coap_sensor_simulation.py
    • opcua_sensor_simulation.py
    • data_visualization.py
    • visualizations/
    • comparison_report.pdf

    Setup & Installation

    1 Install Mosquitto MQTT Broker. 2. Environment:

    python -m venv venv
source venv/bin/activate  # Mac/Linux
.\venv\Scripts\activate   # Windows

3. Dependencies:

Bash

pip install pandas numpy paho-mqtt aiocoap asyncua matplotlib


# How to Run the Simulation:

1. Open five terminal windows and run the following in order:

MQTT Broker: mosquitto
OPC UA Server: python opcua_sensor_simulation.py
CoAP Simulator: python coap_sensor_simulation.py
MQTT Publisher: python mqtt_sensor_simulation.py
Data Visualizer: python data_visualization.py
