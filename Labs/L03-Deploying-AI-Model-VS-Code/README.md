## L03: Deploying via Visual Studio Code
- What I did: I used VS Code and the Edge Impulse CLI to bridge the gap between high-level model training and constrained hardware. I uploaded a .tflite model to Edge Impulse Studio for analysis on a Cortex-M4F microcontroller.
- What I learned: I learned the importance of environmental variables (PATH) and how spatial orientation (like camera distance) affects model inference accuracy.
- Challenges faced: I initially struggled with the Edge Impulse CLI installation, specifically getting the edge-impulse-uploader command to be recognized in my terminal.
