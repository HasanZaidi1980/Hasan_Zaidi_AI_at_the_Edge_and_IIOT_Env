# Lab L07: IIoT Network Analysis (Age of Information & Reliability)
### What I Did in This Lab
In this lab, I conducted a deep-dive analysis into the performance of Industrial Internet of Things (IIoT) networks, specifically focusing on the trade-offs between data freshness and reliability.  Exploratory Data Analysis: I utilized Python (Pandas, Seaborn) to explore a dataset containing 10,000 entries of network parameters like transmission probability, channel quality, and node density.Modeling and Prediction: I implemented and compared two machine learning approaches—a Random Forest Regressor and a Multi-output Deep Learning model—to predict Age of Information (AoI) and Packet Loss Probability (PLP).Visualization: I generated scatter plots, box plots, and correlation heatmaps to visualize how network parameters influence the frequency of "stale" data states.  
### What I Learned
AoI vs. Latency: I learned that AoI is a modern metric that characterizes "freshness" from the receiver's perspective, rather than just the time a packet takes to travel. This is critical for safety-sensitive tasks like AGV collision avoidance.  Traffic Prioritization: I gained a better understanding of the difference between AoI-oriented traffic (continuous status updates like temperature sensors) and deadline-oriented traffic (mission-critical signals like emergency kill-switches).  Model Performance: I discovered that while Random Forest is excellent for feature interpretability (identifying capture_threshold and num_nodes as primary drivers), Deep Learning’s multi-output architecture is more robust for capturing the underlying correlations between data freshness and reliability.
### Challenges Faced
Data Integrity (Infinities): A major hurdle was the presence of mathematical infinities in the AoI column, representing total communication failure. I had to implement a rigorous cleaning phase to treat these as missing data to allow the models to converge.  Variance and Outliers: The IIoT data exhibited extreme volatility, with some AoI values exceeding 50,000 while the median remained very low. Managing these outliers required careful feature scaling and a robust evaluation of model errors (MSE).
